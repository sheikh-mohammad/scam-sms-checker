# Scam SMS Checker

A mobile-first web app for Pakistani families. Paste an SMS or WhatsApp message
(Urdu, Roman Urdu, or English) and get a plain-language verdict in Roman Urdu and
English: **SCAM**, **PROBABLY SCAM**, or **LOOKS SAFE**, with the red flags listed.

Key fact: BISP says its real messages only come from **8171**. Anything claiming to
be BISP from another number is fake.

Built with Next.js, deployed on Vercel. No login, nothing stored.

See [spec.md](./spec.md) for what this app does and does not do.
